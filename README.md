# 🎓 School Projects

### 🤖 Cantonese NLU Benchmarking
`Machine Learning I · Fall 2026`

Five-person Machine Learning project using the **Lee Language Lab's CantoNLU benchmark**.

As the team's **Data Manager**, I profiled and validated datasets, built reusable loading workflows, documented reproducibility requirements, and helped guide feature-engineering decisions based on the data.

**Highlights:**
- Profiled **42,753 language-detection sentences** and **9,999 sentiment reviews**
- Identified **239 duplicated sentences**, including **161 with conflicting labels**
- Found that whitespace tokenization failed for nearly the entire Cantonese language-detection dataset, helping guide the team toward **character n-gram features**
- Built reusable Python loaders with a consistent `(train, val, test)` interface
- Pinned dataset versions and documented source, licence, and reproducibility steps
- Worked through **branches, pull requests, code review, issues, and task checklists**

**Tech:**  
`Python` `Pandas` `Jupyter` `Machine Learning` `NLP` `Git`

[**View Repository →**](https://github.com/babytara/csci3052u-cantonlu)
